# Blueprint — CCNA 200-301 v2.0

## O que colocar aqui

Coloque o PDF oficial Cisco:

```
200-301_CCNA_v2.0_Exam_Topics_PDF.pdf
```

(ou o nome exato do arquivo publicado pela Cisco: *200-301 CCNA v2.0 Exam Topics*.)

Caminho esperado:

```
v2/blueprint/200-301_CCNA_v2.0_Exam_Topics_PDF.pdf
```

## Uso na geração de conteúdo

- O PDF é **mapa de tópicos** (o que o exame cobre e os verbos).
- A geração de content/questions/tickets **não copia** apostilas, e-books ou material de terceiros.
- Conteúdo do banco: original em PT-BR, nível 200-301 v2.0, alinhado a `DECISIONS_v2.md` e `PROMPT_BASE_v2.md`.
